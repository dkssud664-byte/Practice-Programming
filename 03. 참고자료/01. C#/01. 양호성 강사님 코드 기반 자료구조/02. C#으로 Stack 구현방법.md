


# C#으로 Stack 구현방법

구조 설명 : 리스트를 이용한 구현

만드는 순서 :
- 클래스 만들기 - 변수 선언 - 프로퍼티 구현 - 생성자 구현 - Push() - Pop() - Peek()

1. Stack.cs 만들기, 템플릿 클래스로 변환
```csharp
public class Stack<T>
```

<br>

2. 데이터를 저장하기 위해 List 변수 선언
```csharp
private List<T> container;
```
<br>

3. 데이터 개수를 볼 수 있게 프로퍼티 구현
```csharp
public int Count { get { return container.Count; } }
```

<br>

4. 동적할당을 위한 생성자 구현
```csharp
public Stack()
{
    container = new List<T>();
}
```
<br>

5. 데이터를 넣을 수 있게 Push() 구현
```csharp
public void Push(T item)
{
    container.Add(item);
}
```
<br>

6. 데이터를 꺼내 쓸 수 있게 Pop() 구현

```csharp
public T Pop()
{
    if (container.Count == 0)
        throw new InvalidOperationException();

    T item = container[container.Count - 1];
    container.RemoveAt(container.Count - 1);

    return item;
}
```

<br>

7. 마지막에 들어온 데이터를 확인하기 위해 Peek()구현
```csharp
public T Peek()
{
    if(container.Count == 0)
        throw new InvalidOperationException();

    return container[container.Count - 1];
}
```

**총 코드**
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace DataStructure
{
    /*******************************************************************************
     * 어댑터 패턴 (Adapter)
     * 
     * 한 클래스의 인터페이스를 사용하고자 하는 다른 인터페이스로 변환
     * 
     * 어댑터 패턴의 구성 요소
     * 1. 타겟 인터페이스 - 지금 우린 Stack<T> 에서 Push, Pop, Peek이 인터페이스
     * 2. 어댑티 (Adaptee - 변환대상) - 내부에서 사용되는 List<T> 
     * 3. 어댑터 (Adapter - 변환자) - Stack<T> 클래스 자체 (해당 클래스가 List<T> 객체를 감싸서 스택의 인터페이스에 맞게 기능 변환 함)
     * 
     * 구체적으로 무엇이 변환되었나
     * Push() 메서드 - 내부적으로 List<T>의 Add 메서드를 호출해서 리스트의 맨끝에 데이터를 추가하여 Push() 기능으로 변환
     * Pop() 메서드 - List<T>의 맨 끝 요소를 읽어들여 RemoveAt()을 호출하여 맨 끝요소를 제거함으로 Pop() 기능으로 변환
     */

    public class Stack<T>
    {
        private List<T> container;

        public Stack()
        {
            container = new List<T>();
        }

        public int Count { get { return container.Count; } }

        public void Push(T item)
        {
            container.Add(item);
        }

        public T Pop()
        {
            if (container.Count == 0)
                throw new InvalidOperationException();

            T item = container[container.Count - 1];
            container.RemoveAt(container.Count - 1);

            return item;
        }

        public T Peek()
        {
            if(container.Count == 0)
                throw new InvalidOperationException();

            return container[container.Count - 1];
        }
    }
}

```
