
# 두 수의 차 구하기(old)

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/120803



###### 문제 설명

정수  `num1`과  `num2`가 주어질 때,  `num1`에서 `num2`를 뺀 값을 return하도록 soltuion 함수를 완성해주세요.

----------

##### 제한사항

-   -50000 ≤  `num1`  ≤ 50000
-   -50000 ≤  `num2`  ≤ 50000

----------

#### 입출력 예
|num1|num2|result|
|--|--|--|
|2|3|-1|
|100|2|98|

---
**실행 1(성공)**


```csharp
using System;

public class Solution {
    public int solution(int num1, int num2) {
        int answer = 0;
        
        answer = num1 - num2;
        
        return answer;
    }
}
```
