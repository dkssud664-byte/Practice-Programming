
# 금과 은 운반하

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/86053

###### 문제 설명

어느 왕국에 하나 이상의 도시들이 있습니다. 왕국의 왕은 새 도시를 짓기로 결정하였습니다. 해당 도시를 짓기 위해서는 도시를 짓는 장소에 금  `a`  kg과 은  `b`  kg이 전달되어야 합니다.

각 도시에는 번호가 매겨져 있는데,  `i`번 도시에는 금  `g[i]`  kg, 은  `s[i]`  kg, 그리고 트럭 한 대가 있습니다.  `i`번 도시의 트럭은 오직 새 도시를 짓는 건설 장소와  `i`번 도시만을 왕복할 수 있으며, 편도로 이동하는 데  `t[i]`  시간이 걸리고, 최대  `w[i]`  kg 광물을 운반할 수 있습니다. (광물은 금과 은입니다. 즉, 금과 은을 동시에 운반할 수 있습니다.) 모든 트럭은 같은 도로를 여러 번 왕복할 수 있으며 연료는 무한대라고 가정합니다.

정수  `a`,  `b`와 정수 배열  `g`,  `s`,  `w`,  `t`가 매개변수로 주어집니다. 주어진 정보를 바탕으로 각 도시의 트럭을 최적으로 운행했을 때, 새로운 도시를 건설하기 위해 금  `a`  kg과 은  `b`  kg을 전달할 수 있는 가장 빠른 시간을 구해 return 하도록 solution 함수를 완성해주세요.

----------

##### 제한사항

-   0 ≤  `a`,  `b`  ≤ 109
-   1 ≤  `g`의 길이 =  `s`의 길이 =  `w`의 길이 =  `t`의 길이 = 도시 개수 ≤ 105
    -   0 ≤  `g[i]`,  `s[i]`  ≤ 109
    -   1 ≤  `w[i]`  ≤ 102
    -   1 ≤  `t[i]`  ≤ 105
    -   `a`  ≤  `g`의 모든 수의 합
    -   `b`  ≤  `s`의 모든 수의 합

----------

##### 입출력 예

|a|b|g|s|w|t|result|
|-|-|-|-|-|-|-|
|10|10|[100]|[100]|[7]|[10]|50|
|90|500|[70,70,0]|[0,0,500]|[100,100,2]|[4,8,1]|499|

----------

##### 입출력 예 설명

**입출력 예 #1**

-   도시가 오직 하나뿐이므로, 0번 도시의 유일한 트럭이 모든 운반을 해결해야 합니다. 이 트럭은 최대 7kg만큼의 광물을 운반할 수 있으며 편도 완주에는 10시간이 걸립니다.
-   맨 처음에 10시간을 써서 7kg만큼의 금을 운반하고, 10시간을 써서 다시 도시로 돌아오고, 10시간을 써서 7kg만큼의 은을 운반하고, 10시간을 써서 다시 도시로 돌아오고, 마지막으로 10시간을 써서 3kg만큼의 금과 3kg만큼의 은을 운반하면, 총 50시간 만에 필요한 모든 금과 은을 조달할 수 있습니다.
-   따라서, 50을 return 해야 합니다.

**입출력 예 #2**

-   도시가 3개이고, 0번과 1번 도시는 금만 70kg씩 가지고 있고 2번 도시는 은을 500kg 가지고 있습니다.
    -   0번 도시의 트럭은 용량은 100kg, 편도 완주 시간은 4시간입니다.
    -   1번 도시의 트럭은 용량은 100kg, 편도 완주 시간은 8시간입니다.
    -   2번 도시의 트럭은 용량은 2kg, 편도 완주 시간은 1시간입니다.
-   금은 0번 도시의 트럭과 1번 도시의 트럭이 각각 45kg씩 나누어서 운반하면 8시간 안에 필요한 모든 금을 조달할 수 있습니다.
-   은은 2번 도시의 트럭이 한 번에 2kg씩 250번 운반하면(249번 왕복 + 1번 편도) 총 499시간 만에 필요한 모든 은을 조달할 수 있습니다.
-   따라서, 499를 return 해야 합니다.

**실행 1(실패)**
생각 : 트럭 구조체를 만들어 실제 운반과 똑같이 구현한다.
결과 : 테스트 1번 제외하고 실패, 시간초과
실패 이유 : 실제 현실과 동일한 동작방식으로 처리했다.

```csharp
using System;

public class Solution {
    public struct Truck
    {
        public int maxWeight;
        public int gold;
        public int silver;
        public int time;
        public int CurrentWeight => gold + silver;

        public void Init(int maxWeight, int gold, int silver, int time)
        {
            this.maxWeight = maxWeight;
            this.gold = gold;
            this.silver = silver;
            this.time = time;
        }
    }

    
    public long solution(int a, int b, int[] g, int[] s, int[] w, int[] t)
    {
        long answer = 0;
        int capacity = g.Length;
        int gold = 0;
        int silver = 0;
        int maxTime = 0;

        Truck[] trucks = new Truck[capacity];

        //트럭 구조체 초기화
        for (int i = 0; i < capacity; i++)
        {
            trucks[i].Init(w[i], 0, 0, 0);
        }

        //편도
        for (int i = 0; i < capacity; i++)
        {
            if (gold < a && g[i] > 0)
            {
                int temp = 0;
                if (g[i] > trucks[i].maxWeight + 1)
                {
                    temp = trucks[i].maxWeight;
                }
                else
                {
                    temp = g[i] % (trucks[i].maxWeight + 1);
                }

                if (temp + gold > a)
                {
                    temp = a - gold;
                }
                trucks[i].gold += temp;
                g[i] -= temp;
                trucks[i].time += t[i];
            }
            else if (silver < b && s[i] > 0)
            {
                int temp = 0;
                if (s[i] > trucks[i].maxWeight + 1)
                {
                    temp = trucks[i].maxWeight;
                }
                else
                {
                    temp = s[i] % (trucks[i].maxWeight + 1);
                }

                if (temp + silver > b)
                {
                    temp = b - silver;
                }
                trucks[i].silver += temp;
                s[i] -= temp;
                trucks[i].time += t[i];
            }

            //무게가 남으면 은을 채워 넣는다
            if (trucks[i].CurrentWeight < trucks[i].maxWeight)
            {
                int temp = 0;
                if (s[i] > trucks[i].maxWeight + 1)
                {
                    temp = trucks[i].maxWeight;
                }
                else
                {
                    temp = s[i] % (trucks[i].maxWeight + 1);
                }

                if (temp + silver > b)
                {
                    temp = b - silver;
                }
                trucks[i].silver += temp;
                s[i] -= temp;
            }

            gold += trucks[i].gold;
            trucks[i].gold = 0;
            silver += trucks[i].silver;
            trucks[i].silver = 0;
        }

        //왕복
        while (gold < a || silver < b)
        {
            int i = 0;
            while (i < capacity)
            {
                if (gold < a && g[i] > 0)
                {
                    int temp = 0;
                    if (g[i] > trucks[i].maxWeight + 1)
                    {
                        temp = trucks[i].maxWeight;
                    }
                    else
                    {
                        temp = g[i] % (trucks[i].maxWeight + 1);
                    }

                    if (temp + gold > a)
                    {
                        temp = a - gold;
                    }
                    trucks[i].gold += temp;
                    g[i] -= temp;
                    trucks[i].time += t[i] * 2;
                }
                else if (silver < b && s[i] > 0)
                {
                    int temp = 0;
                    if (s[i] > trucks[i].maxWeight + 1)
                    {
                        temp = trucks[i].maxWeight;
                    }
                    else
                    {
                        temp = s[i] % (trucks[i].maxWeight + 1);
                    }

                    if (temp + silver > b)
                    {
                        temp = b - silver;
                    }
                    trucks[i].silver += temp;
                    s[i] -= temp;
                    trucks[i].time += t[i] * 2;
                }

                //무게가 남으면 은을 채워 넣는다
                if (s[i] > 0 && trucks[i].CurrentWeight < trucks[i].maxWeight)
                {
                    int temp = 0;
                    if (s[i] > trucks[i].maxWeight + 1)
                    {
                        temp = trucks[i].maxWeight;
                    }
                    else
                    {
                        temp = s[i] % (trucks[i].maxWeight + 1);
                    }

                    if (temp + silver > b)
                    {
                        temp = a - silver;
                    }
                    trucks[i].silver += temp;
                    s[i] -= temp;
                }

                gold += trucks[i].gold;
                trucks[i].gold = 0;
                silver += trucks[i].silver;
                trucks[i].silver = 0;
                i++;
            }
        }

        //트럭의 가장 높은 시간을 반환
        for (int i = 0; i < capacity; i++)
        {
            if (maxTime < trucks[i].time)
            {
                maxTime = trucks[i].time;
            }
        }

        return answer = maxTime;
    }
}
```

**실행 2()**
생각 : 질문하기와 gpt에 힌트를 물어보니 이분탐색을 써야 시간안에 풀 수 있고 시간안에 몇 번 왕복이 가능한지를 한 번에 계산하라는 힌트를 얻었다.

먼저 각 트럭이 금과 은을 얼마만에 옮길수 있는지를 한 번에 계산한뒤 비교해보자

결과 : 중도포기

중간 점검으로 gpt에 물어보니 방향성이 안맞고 이분탐색이 아니다

```csharp
    public struct Truck
    {
        public int gold;
        public int silver;
        public int time;
        public int goldTime;
        public int silverTime;
        public int driveTime;
        public int OneWayRepeatCount => time / driveTime;
    }

    static public long solution(int a, int b, int[] g, int[] s, int[] w, int[] t)
    {
        long answer = 0;
        int capacity = g.Length;    //도시 개수
        int tGoldQuantity = 0;
        int tSilverQuantity = 0;
        
        //트럭 생성
        Truck[] trucks = new Truck[capacity];

        //옮기는 시간 넣기
        TruckCarryTime(trucks, g, s, w, t);

        //모든 트럭이 t 1당 옮기는 양
        for(int i = 0; i < capacity; i++)
        {
            if (trucks[i].gold > 0)
            {
                tGoldQuantity += trucks[i].gold / trucks[i].goldTime;
            }
            if (trucks[i].silver > 0)
            {
                tSilverQuantity += trucks[i].silver / trucks[i].silverTime;
            }
        }



        return answer;
    }

    static public void TruckCarryTime(Truck[] trucks, int[] g, int[] s, int[] w,  int[] t)
    {
        //각 도시의 자원을 옮기는데 걸리는 시간
        for (int i = 0; i < trucks.Length; i++)
        {
            //금 옮기는 시간
            int repeat = 0;
            int remain = 0;
            repeat = g[i] / w[i];
            //금이 있고 가진 g < w이면 횟수 추가
            if (g[i] > 0 && repeat == 0)
            {
                repeat++;
                g[i] = 0;
            }
            remain = g[i] % w[i];
            trucks[i].gold = g[i];
            g[i] = remain;
            trucks[i].driveTime = t[i];
            trucks[i].time = repeat * t[i] * 2;
            trucks[i].goldTime = repeat * t[i] * 2;

            //남은 용량은 은을 가져간다
            s[i] += g[i];
            g[i] = 0;

            //은 옮기는 시간
            repeat = s[i] / w[i];
            //은이 있고 가진 g < w이면 횟수 추가
            if (s[i] > 0 && repeat == 0)
            {
                repeat++;
                s[i] = 0;
            }
            remain = s[i] % w[i];
            trucks[i].silver = s[i];
            trucks[i].time = repeat * t[i] * 2;
            trucks[i].silverTime = repeat * t[i] * 2;

            //편도 시간 빼기
            trucks[i].time -= t[i];
        }
    }
}
```

**실행 3(성공)**
생각 : 이분탐색을 공부해야겠다

gpt에 물어보니 5단계로 나누어 설명해준다고 한다.
설명을 듣고 파라메트릭 서치 기본형을 이해하게 되고 5단계까지 따라가다보니 문제가 이해가 되었다.

결과 : 성공


```csharp
using System;

public class Solution {
    public long solution(int a, int b, int[] g, int[] s, int[] w, int[] t)
    {
        long answer = 0;
        long left = 0;
        long right = 4_000_000_000_000_000L;
        answer = right;

        while(left <= right)
        {
            long mid = (left + right) / 2;

            if (Possible(mid, g, s, w, t, a, b))
            {
                answer = mid;
                right = mid - 1;
            }
            else
            {
                left = mid + 1;
            }

        }


        return answer;
    }

    public bool Possible(long time, int[] g, int[] s, int[] w, int[] t, int gold, int silver)
    {
        long totalGold = 0;
        long totalSilver = 0;
        long totalSum = 0;

        for (int i = 0; i < g.Length; i++)
        {
            long round = 2L * t[i];
            long count = time / round;

            if (time % round >= t[i])
            {
                count++;
            }

            long maxCarry = count * w[i];

            long goldMoved = Math.Min(maxCarry, g[i]);
            long silverMoved = Math.Min(maxCarry, s[i]);

            totalGold += goldMoved;
            totalSilver += silverMoved;

            totalSum += Math.Min(maxCarry, g[i] + s[i]);
        }

        return totalGold >= gold && totalSilver >= silver && totalSum >= gold + silver;
    }
}
```

# 🚚 1단계: “트럭 왕복 횟수 계산” 기본 예제

이 단계에서는 금/은/적재량은 전혀 고려하지 않는다.  
오직 **시간 T 동안 트럭이 몇 번 왕복할 수 있는지**만 계산해보는 연습이다.

----------

# 🎯 문제(1단계)

**각 트럭은 왕복하는 데 시간이 A[i] * 2 걸린다. (편도 A[i])**  
어떤 특정 시간 T가 주어졌을 때,  
각 트럭이 **완전한 왕복**을 몇 번 할 수 있는지 계산해라.

그리고 **편도만 가능한 경우에는 +1을 해주는지**도 구해보자.

----------

## 📌 예제 입력

트럭마다 걸리는 편도 시간 t:

`t = [5, 7, 3]` 

총 시간 T:

`T = 20` 

----------

# 🧠 풀이 원리

### 🔸 왕복 1번 = t[i] * 2

### 🔸 왕복 가능 횟수 = T / (t[i] * 2)

### 🔸 왕복하고 남은 시간이 편도(t[i])보다 크면:

→ 왕복은 못 하지만 **편도만 가능한 것** → +1

----------

# 🎉 정답 계산 (설명형)

### 1번 트럭 (t = 5)

-   왕복 = 10
    
-   T = 20
    
-   → 20 / 10 = 2번 왕복 가능
    
-   남은 시간 = 20 - 20 = 0 → 편도 불가
    
-   **결과: 왕복 2, 편도 0**
    

### 2번 트럭 (t = 7)

-   왕복 = 14
    
-   T = 20
    
-   → 20 / 14 = 1번 왕복
    
-   남은 시간 = 20 - 14 = 6 → 편도 불가 (편도 = 7 > 6)
    
-   **결과: 왕복 1, 편도 0**

# 🎯 문제(2단계)

기계들이 있다.

`m = [2, 3, 7]   // 기계 3대` 

각 기계는

-   첫 번째 기계: 작업 1개당 2초
    
-   두 번째 기계: 작업 1개당 3초
    
-   세 번째 기계: 작업 1개당 7초
    

우리가 처리해야 하는 총 작업량:

`N = 10`

# 🧠 핵심 개념

### 파라메트릭 서치의 핵심은 단 하나:

### **"특정 시간 T가 주어졌을 때, 조건을 만족할 수 있는가?"**

그리고 그 기준으로 T를 줄였다 늘렸다 하며 이분 탐색한다.

----------

# 🧪 예시 “가능 여부 판단 함수”: Possible(T)

T 시간 안에 처리 가능한 총 작업 수는?

각 기계가:

`T / m[i] 만큼 작업할 수 있음` 

그래서:

`total = Σ (T / m[i])` 

그리고

`total >= N => 가능 (true)
total < N => 불가능 (false)` 

----------

# 🧩 C# 구현(2단계)

`bool  Possible(long T, int[] m, long N)
{ long work = 0; for (int i = 0; i < m.Length; i++)
    {
        work += T / m[i]; if (work >= N) return  true; // 조기 종료 } return work >= N;
}` 

----------

# 🧠 이 단계에서 꼭 알아야 할 점

-   **파라메트릭 서치는 “가능/불가능 판단 함수”가 핵심이다.**
    
-   정답(T)을 직접 찾지 않는다.
    
-   “이 시간에 가능?”만 묻는다.
    
-   이 함수가 있으면 나중에 **이분 탐색으로 최소 T를 찾는다.**
    

----------

# 🧩 파라메트릭 서치 전체 구조

`long  Solve(int[] m, long N)
{ long left = 0; long right = 1_000_000_000_000_000L; // 충분히 큰 값 (limit)  long answer = right; while (left <= right)
    { long mid = (left + right) / 2; if (Possible(mid, m, N))
        {
            answer = mid; // mid 시간 안에 가능함 → 더 작은 시간도 가능성 있음 right = mid - 1;
        } else {
            left = mid + 1; // mid 시간 안에는 부족 → 더 큰 시간 필요 }
    } return answer;
}`

# 🎯 문제(3단계)

기계들이 있다.

-   기계마다 a[i] = 1초에 생산 가능한 A 자원
    
-   기계마다 b[i] = 1초에 생산 가능한 B 자원
    

우리는 다음 목표를 만족시켜야 한다:

-   A 자원을 최소 A_need만큼
    
-   B 자원을 최소 B_need만큼
    

특정 시간 **T 안에 가능한가? → Possible(T)**  
을 판단하는 함수를 만들어보자.

----------

# 📌 예제 데이터

`a = [1, 2, 3] b = [2, 1, 0] A_need = 10  B_need = 8`

# 🧠 핵심 구조

시간 T가 주어졌을 때:

`각 기계가 생산하는 A 총량 = Σ (a[i]  *  T) 각 기계가 생산하는 B 총량 = Σ (b[i]  *  T)` 

그리고 동시에:

`A_total >= A_need
B_total >= B_need` 

이면 **true**, 아니면 false.

----------

# 🧩 복합 조건 Possible 함수(3단계)

`bool  Possible(long T, int[] a, int[] b, long needA, long needB)
{ long totalA = 0; long totalB = 0; for (int i = 0; i < a.Length; i++)
    {
        totalA += a[i] * T;
        totalB += b[i] * T; if (totalA >= needA && totalB >= needB) return  true; // 조기 종료 } return totalA >= needA && totalB >= needB;
}` 

----------

# 🌟 이 단계에서 중요한 점

### ✔ 여러 자원을 동시에 확인하기 때문에

단순히 하나의 조건만 보는 2단계보다 구조가 한 단계 더 커짐

### ✔ 동시에 만족해야 하므로 AND 조건이 됨

### ✔ “가능/불가능”만 판단하는 함수다

최소 시간은 여기서 찾지 않고  
**4단계에서 이분 탐색으로 묶어서 최소 T를 찾는다.**

----------

# 🧩 전체 파라메트릭 구조(예시)

`long  Solve(int[] a, int[] b, long needA, long needB)
{ long left = 0; long right = 1_000_000_000_000L; long answer = right; while (left <= right)
    { long mid = (left + right) / 2; if (Possible(mid, a, b, needA, needB))
        {
            answer = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    } return answer;
}`

        → 이런 구조로 확장된다.

# ✅ **5단계 — 금과 은 운반 문제: 전체 파라매트릭 서치 로직 완성**

-   각 도시마다 금 `g[i]`, 은 `s[i]`, 이동 시간 `t[i]`, 한 번에 이동 가능 용량 `w[i]`가 있음

# ✅ **1) “시간 T 안에 운반 가능한가?” 판단 함수**

시간 T가 주어지면,

각 도시에서 **왕복(2*t[i])** + **편도 한 번(t[i]) 추가** 가능.

즉, 한 도시에서 T동안 운반 가능한 횟수:

`k =  T  /  (2  * t[i])  (왕복 횟수)  if  (T % (2  * t[i])  >= t[i]) k++  (편도 한 번 더 가능)` 

각 도시에서 운반할 수 있는 총 무게:

`carry = k * w[i]` 

그리고 금 + 은 제한:

`gold_possible = min(g[i], carry) silver_possible = min(s[i], carry) total_possible = min(g[i] + s[i], carry)` 

----------

# ✅ **2) T 시간 안에 금 a, 은 b를 충족할 수 있는지 체크**

모든 도시의 값을 합산:

`sumGold  
sumSilver sumTotal  (금+은 섞어서)` 

조건:

`sumGold >= a
sumSilver >= b
sumTotal  >= a + b` 

이 세 조건을 모두 충족하면 T 시간에 가능!

----------

# 💡 왜 sumTotal 조건이 필요한가?

예를 들어:

-   금은 충분 → 금 10, 은 10
    
-   목표: 금 5, 은 5 → 조건 만족
    

하지만 어떤 경우는:

-   금은 각각 충분하지만,
    
-   “운반 가능 총량 carry가 부족하면” 목적 달성 불가
    

그래서 총량 체크가 필요함.

# ✅ **3) 전체 파라매트릭 서치 코드 예시 (C#)**

아래는 전체 구조가 완성된 최종 코드야.

`public  class  Solution { public  long  solution(int a, int b, int[] g, int[] s, int[] w, int[] t) { long left = 0; long right = 4_000_000_000_000_000L; // 최대 시간  long answer = right; while (left <= right) { long mid = (left + right) / 2; // mid 시간 안에 금/은 운반 가능한가?  if (CanCarry(mid, a, b, g, s, w, t)) {
                answer = mid;
                right = mid - 1; // 더 최소 시간 찾기 } else {
                left = mid + 1; // 더 긴 시간이 필요함 }
        } return answer;
    } private  bool  CanCarry(long time, int a, int b, int[] g, int[] s, int[] w, int[] t)
    { long goldSum = 0; long silverSum = 0; long totalSum = 0; for (int i = 0; i < g.Length; i++) { long roundTrip = 2L * t[i]; long cnt = time / roundTrip; if (time % roundTrip >= t[i]) cnt++; long maxCarry = cnt * (long)w[i];

            goldSum  += Math.Min(maxCarry, g[i]);
            silverSum += Math.Min(maxCarry, s[i]);
            totalSum += Math.Min(maxCarry, g[i] + s[i]);
        } return goldSum >= a && silverSum >= b && totalSum >= a + b;
    }
}`

# ✅ **4) 이 로직이 왜 작동하는가? (핵심 요약)**

-   “T 시간 안에 가능한가?”는 **그리디로 판별 가능**
    
-   하지만 T는 0 ~ 매우 큰 값(4조) 범위 → 직접 탐색 불가
    
-   그래서 가능한 T 중 최소 T를 찾기 위해 **이분 탐색**
    
-   각 중간 시간 mid에서 가능한지 계산 → 맞으면 줄이고, 아니면 늘리고
    
-   결국 조건을 만족하는 최소 시간을 찾게 됨
