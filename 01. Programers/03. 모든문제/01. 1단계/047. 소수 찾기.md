
# 소수 찾기

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/12921

###### 문제 설명

1부터 입력받은 숫자 n 사이에 있는 소수의 개수를 반환하는 함수, solution을 만들어 보세요.

소수는 1과 자기 자신으로만 나누어지는 수를 의미합니다.  
(1은 소수가 아닙니다.)

##### 제한 조건

-   n은 2이상 1000000이하의 자연수입니다.

##### 입출력 예

|n|result|
|-|-|
|10|4|
|5|3|

##### 입출력 예 설명

입출력 예 #1  
1부터 10 사이의 소수는 [2,3,5,7] 4개가 존재하므로 4를 반환

입출력 예 #2  
1부터 5 사이의 소수는 [2,3,5] 3개가 존재하므로 3를 반환

---
**실행 1(실패)**
생각 : n까지 모든 소수를 찾아 answer에 반환한다.
결과 : 테스트 11번 실패
실패 이유 : 시간초과

```csharp
public class Solution {
    public int solution(int n) {
        int answer = 0;

        for (int i = 2; i <= n; i++)
        {
            int prime = 0;

            for (int j = 1; j <= i / 2; j++)
            {
                if(prime > 1)
                {
                    break;
                }

                if(i % j == 0)
                {
                    prime++;
                }
            }
            if(prime == 1)
            {
                answer++;
            }
        }

        return answer;
    }
}
```
---
**실행 1(성공)**
생각 : 검색을 해보니 소수인지 판별을 하고 싶으면 n의 루트 n까지만 검사하면 된다고 한다.

결과 : 성공

```csharp
public class Solution {
    public int solution(int n) {
        int answer = 0;

        for (int i = 2; i <= n; i++)
        {
             if(IsPrime(i))
             {
                 answer++;
             }
        }

        return answer;
    }
    
    bool IsPrime(int n)
    {
        if(n < 2)
        {
            return false;
        }

        for(int i = 2; i * i <= n; i++)
        {
            if(n % i == 0)
            {
                return false;
            }
        }
        return true;
    }
}
```
