
# 덧칠하기

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/161989

###### 문제 설명

어느 학교에 페인트가 칠해진 길이가  `n`미터인 벽이 있습니다. 벽에 동아리 · 학회 홍보나 회사 채용 공고 포스터 등을 게시하기 위해 테이프로 붙였다가 철거할 때 떼는 일이 많고 그 과정에서 페인트가 벗겨지곤 합니다. 페인트가 벗겨진 벽이 보기 흉해져 학교는 벽에 페인트를 덧칠하기로 했습니다.

넓은 벽 전체에 페인트를 새로 칠하는 대신, 구역을 나누어 일부만 페인트를 새로 칠 함으로써 예산을 아끼려 합니다. 이를 위해 벽을 1미터 길이의 구역  `n`개로 나누고, 각 구역에 왼쪽부터 순서대로 1번부터  `n`번까지 번호를 붙였습니다. 그리고 페인트를 다시 칠해야 할 구역들을 정했습니다.

벽에 페인트를 칠하는 롤러의 길이는  `m`미터이고, 롤러로 벽에 페인트를  **한 번**  칠하는 규칙은 다음과 같습니다.

-   롤러가 벽에서 벗어나면 안 됩니다.
-   구역의 일부분만 포함되도록 칠하면 안 됩니다.

즉, 롤러의 좌우측 끝을 구역의 경계선 혹은 벽의 좌우측 끝부분에 맞춘 후 롤러를 위아래로 움직이면서 벽을 칠합니다. 현재 페인트를 칠하는 구역들을 완전히 칠한 후 벽에서 롤러를 떼며, 이를 벽을  **한 번**  칠했다고 정의합니다.

한 구역에 페인트를 여러 번 칠해도 되고 다시 칠해야 할 구역이 아닌 곳에 페인트를 칠해도 되지만 다시 칠하기로 정한 구역은 적어도 한 번 페인트칠을 해야 합니다. 예산을 아끼기 위해 다시 칠할 구역을 정했듯 마찬가지로 롤러로 페인트칠을 하는 횟수를 최소화하려고 합니다.

정수  `n`,  `m`과 다시 페인트를 칠하기로 정한 구역들의 번호가 담긴 정수 배열  `section`이 매개변수로 주어질 때 롤러로 페인트칠해야 하는 최소 횟수를 return 하는 solution 함수를 작성해 주세요.

----------

##### 제한사항

-   1 ≤  `m`  ≤  `n`  ≤ 100,000
-   1 ≤  `section`의 길이 ≤  `n`
    -   1 ≤  `section`의 원소 ≤  `n`
    -   `section`의 원소는 페인트를 다시 칠해야 하는 구역의 번호입니다.
    -   `section`에서 같은 원소가 두 번 이상 나타나지 않습니다.
    -   `section`의 원소는 오름차순으로 정렬되어 있습니다.

----------

##### 입출력 예

|n|m|section|result|
|-|-|-|-|
|8|4|[2, 3, 6]|2|
|5|4|[1, 3]|1|
|4|1|[1, 2, 3, 4]|4|

----------

**실행 1(실패)**
생각 : n을 bool배열로 관리하고 m만큼 칠해서 몇번 칠했는지 반환한다 m이 구역을 벗어나는것에대해 예외처리를 해야할지는 의문이다

결과 : 2, 6, 13, 41 케이스 실패

실패 이유 : 시간초과

```csharp
using System;

public class Solution {
    public int solution(int n, int m, int[] section) {
        int answer = 0;

        //구역
        bool[] isPaint = new bool[n];
        bool allFalse = false;

        //페인트 칠을 해야할 곳 = true
        for(int i = 0; i < section.Length; i++)
        {
            isPaint[--section[i]] = true;
        }

        while(!allFalse)
        {
            //m만큼 페인트 칠(왼 -> 오)
            for(int i = 0; i < n - m; i++)
            {
                if (isPaint[i])
                {
                    answer++;
                    for(int j = i; j < i + m; j++)
                    {
                        isPaint[j] = false;
                    }
                }
            }
            //m만큼 페인트 칠(오 -> 왼)
            for (int i = n - 1; i >= m; i--)
            {
                if (isPaint[i])
                {
                    answer++;
                    for (int j = i; j >= i - m; j--)
                    {
                        isPaint[j] = false;
                    }
                }
            }

            //전부 칠했는지 체크
            for (int i = 0; i < isPaint.Length; i++)
            {
                allFalse = true;
                if (isPaint[i])
                {
                    allFalse = false;
                }
            }
        }

        return answer;
    }
}
```

public class Solution {
    public int solution(int n, int m, int[] section) {

            }
        }

# ✅ **좋은 점**

### 1) **핵심 그리디 로직을 정확히 구현함**

-   현재 위치 `i`가 칠해야 하는 구역이면
    
-   롤러 길이(m)만큼 오른쪽을 쭉 칠하고
    
-   그 끝 지점까지 인덱스를 점프한다
    

이 로직은 문제의 공식적인 최적해 방식(탐욕법)과 동일해.

----------

### 2) **전체 구간을 순회하면서 추가적인 반복이 없음**

-   한 번의 for문 안에서 해결
    
-   section을 정렬하거나 별도의 자료구조를 만들 필요 없음
    

----------

### 3) **직관적으로 명확한 코드**

-   boolean 배열을 사용해 칠할 위치 표시 → 직관적
    
-   로직이 한눈에 보임

# ⚠️ **주의 또는 개선 포인트**

## 1) 성능을 더 개선할 수 있음 (현재도 통과는 됨)

현재 방식:

-   `isPaint` 배열 크기 = n (최대 100,000)
    
-   loop도 최대 n → **O(n)** 으로 충분히 빠르긴 함.
    

하지만 **더 최적화된 공식 풀이들은 boolean 배열도 안 쓰고**,  
section 배열만 순회해서 해결함 → **O(section.Length)**

(너 코드도 빠르지만, 조금 더 메모리를 줄일 수 있다는 의미)

----------

## 2) section 배열을 직접 변경(`--section[i]`)하는 건 위험할 수 있음

입력 배열을 직접 변경하면,  
재사용할 때 오류를 만들 위험이 있음.

조금 더 안전한 방식:

`isPaint[section[i] - 1] = true;` 

----------

## 3) m 칠하기 루프에서 tempIndex는 불필요하게 갱신됨

현재:

`for (int j = i; j < i + m; j++)
{ if(j >= isPaint.Length)
    { break;
    }
    isPaint[j] = false;
    tempIndex = j;
}` 

이 경우 tempIndex = i+m-1가 될 것 같지만  
벽 끝에서 커트될 수 있으므로 유지해야 하긴 해.

즉, **설계 자체는 올바름**.

----------

## 4) allFalse 같은 변수는 제거해도 됨

사용하지 않는 변수는 유지할 필요 없음.

# ⭐ 추천하는 더 간결한 버전 (참고용)

boolean 배열 없이 section만 이용해 푸는 최적 풀이:

`public  int  solution(int n, int m, int[] section) { int answer = 0; int paintedUntil = 0; foreach (int s in section) { if (s > paintedUntil) {
            answer++;
            paintedUntil = s + m - 1;
        }
    } return answer;
}` 

-   section이 정렬된 상태(문제 보장)
    
-   boolean 배열 필요 없음
