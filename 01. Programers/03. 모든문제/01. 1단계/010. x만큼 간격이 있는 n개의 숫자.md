
# x만큼 간격이 있는 n개의 숫자

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/12954



###### 문제 설명

함수 solution은 정수 x와 자연수 n을 입력 받아, x부터 시작해 x씩 증가하는 숫자를 n개 지니는 리스트를 리턴해야 합니다. 다음 제한 조건을 보고, 조건을 만족하는 함수, solution을 완성해주세요.

#### 제한 조건

-   x는 -10000000 이상, 10000000 이하인 정수입니다.
-   n은 1000 이하인 자연수입니다.

#### 입출력 예

|x|n|answer|
|-|-|-|
|2|5|[2,4,6,8,10]|
|4|3|[4,8,12]|
|-4|2|[-4, -8]|

---
**실행 1(성공)**
생각 : n만큼의 배열에 x * 1 ~ n까지 넣는다
결과 : 성공

```csharp
using System.Linq;

public class Solution {
    public long[] solution(int x, int n) {
        long[] answer = Enumerable.Range(1, n).Select(i => (long)x * i).ToArray();

        return answer;
    }
}
```

**후기**
링큐를 써보았는데 역시 익숙하지 않다
이해하고 만드는데 gpt의 도움을 많이 받았다.

Range만큼 반복하고 1부터 n까지 증가되는 i를 Select로 선택하고 i 의 값을 x와 곱해준 뒤 배열로 반환한다.
