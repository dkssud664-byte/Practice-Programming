
# JadenCase 문자열 만들기

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/12951

###### 문제 설명

JadenCase란 모든 단어의 첫 문자가 대문자이고, 그 외의 알파벳은 소문자인 문자열입니다. 단, 첫 문자가 알파벳이 아닐 때에는 이어지는 알파벳은 소문자로 쓰면 됩니다. (첫 번째 입출력 예 참고)  
문자열 s가 주어졌을 때, s를 JadenCase로 바꾼 문자열을 리턴하는 함수, solution을 완성해주세요.

##### 제한 조건

-   s는 길이 1 이상 200 이하인 문자열입니다.
-   s는 알파벳과 숫자, 공백문자(" ")로 이루어져 있습니다.
    -   숫자는 단어의 첫 문자로만 나옵니다.
    -   숫자로만 이루어진 단어는 없습니다.
    -   공백문자가 연속해서 나올 수 있습니다.

##### 입출력 예

|s|return|
|-|-|
|"3people unFollowed me"|"3people Unfollowed Me"|
|"for the last week"|"For The Last Week"|

**실행 1(실패)**
생각 : 모두 소문자로 만든 뒤 첫 글자만 영어면 대문자로 바꿔준다.

결과 : 실패

실패 이유 : 연속된 공백이 있을경우 런타임 에러가 뜬다.

```csharp
public string solution(string s)
        {
            string answer = "";

            string[] split = s.ToLower().Split(' ');

            for(int i = 0; i < split.Length; i++)
            {
                split[i] = char.ToUpper(split[i][0]) + split[i].Substring(1);
                answer += split[i];
                
                if(i < split.Length - 1)
                {
                    answer += ' ';
                }
            }

            return answer;
        }
```

**실행 2(성공)**
생각 : char형으로 나눠서 검사해본다

결과 : 성공

```csharp
public class Solution {
    public string solution(string s) {
        string answer = "";

        char[] chars = s.ToLower().ToCharArray();

        bool isFirst = true;

        for(int i = 0; i < chars.Length; i++)
        {
            bool isWord = true;

            if(chars[i] == ' ')
            {
                answer += ' ';
                isWord = false;
                isFirst = true;
                continue;
            }

            if(!isFirst)
            {
                answer += chars[i];
            }
            else
            {
                answer += char.ToUpper(chars[i]);
                isFirst = false;
            }
        }

        return answer;
    }
}
```
