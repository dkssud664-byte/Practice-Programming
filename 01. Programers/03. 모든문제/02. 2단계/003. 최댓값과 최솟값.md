
# 최댓값과 최솟값

링크 : https://school.programmers.co.kr/learn/courses/30/lessons/12939

###### 문제 설명

문자열 s에는 공백으로 구분된 숫자들이 저장되어 있습니다. str에 나타나는 숫자 중 최소값과 최대값을 찾아 이를 "(최소값) (최대값)"형태의 문자열을 반환하는 함수, solution을 완성하세요.  
예를들어 s가 "1 2 3 4"라면 "1 4"를 리턴하고, "-1 -2 -3 -4"라면 "-4 -1"을 리턴하면 됩니다.

##### 제한 조건

-   s에는 둘 이상의 정수가 공백으로 구분되어 있습니다.

##### 입출력 예

|s|return|
|-|-|
|"1 2 3 4"|"1 4"|
|"-1 -2 -3 -4"|"-4 -1"|
|"-1 -1"|"-1 -1"|

**실행 1(실패)**
생각 : 문자열의 숫자만 리스트에 저장하고 min과 max를 출력한다.
결과 :  실패 
테스트 케이스를 제외한 모든 케이스 실패
실패 이유 : 두자리수 이상의 숫자를 고려하지 않고있다

```csharp
using System.Collections.Generic;
using System.Linq;

public class Solution {
    public string solution(string s) {
        string answer = "";
        List<int> list = new List<int>();
        bool isMinus = false;

        foreach(char c in s)
        {
            if(char.IsNumber(c))
            {
                int num = c - '0';
                if (isMinus)
                {
                    list.Add(-num);
                    isMinus = false;
                }
                else
                {
                    list.Add(num);
                }
            }
            else if(c == '-')
            {
                isMinus = true;
            }
        }

        answer += list.Min().ToString();
        answer += " ";
        answer += list.Max().ToString();

        return answer;
    }
}
```

**실행 1(성공)**
생각 : 두자리 수 이상의 숫자도 고려해보자
공백이나올때까지 숫자를 더한다.

결과 : 성공

```csharp
using System.Collections.Generic;
using System.Linq;

public class Solution {
    public string solution(string s) {
        string answer = "";
        List<int> list = new List<int>();
        bool isMinus = false;
        string strNum = "";

        for(int i = 0; i < s.Length; i++)
        {
            if(s[i] == '-')
            {
                isMinus = true;
            }
            else if (char.IsNumber(s[i]))
            {
                strNum += s[i];
            }

            if (s[i] == ' ' || i == s.Length - 1)
            {
                if (isMinus)
                {
                    list.Add(-int.Parse(strNum));
                    isMinus = false;
                }
                else
                {
                    list.Add(int.Parse(strNum));
                }
                strNum = "";
            }
        }

        answer += list.Min().ToString();
        answer += " ";
        answer += list.Max().ToString();

        return answer;
    }
}
```
