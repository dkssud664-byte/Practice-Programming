

# 소인수분해

링크 : https://www.acmicpc.net/problem/11653





## 문제

정수 N이 주어졌을 때, 소인수분해하는 프로그램을 작성하시오.

## 입력

첫째 줄에 정수 N (1 ≤ N ≤ 10,000,000)이 주어진다.

## 출력

N의 소인수분해 결과를 한 줄에 하나씩 오름차순으로 출력한다. N이 1인 경우 아무것도 출력하지 않는다.

## 예제 입력 1

72

## 예제 출력 1

2
2
2
3
3

## 예제 입력 2

3

## 예제 출력 2

3

## 예제 입력 3

6

## 예제 출력 3

2
3

## 예제 입력 4

2

## 예제 출력 4

2

## 예제 입력 5

9991

## 예제 출력 5

97
103

**실행 1(성공)**

```c++
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

int main()
{
	int num;
	int max, sum, count = 0;
	vector<int> vArr;

	cin >> num;
	max = num;

	//입력값이 소수인지 판별
	for (int i = 1; i <= sqrt(num); i++)
	{
		if (num % i == 0 && num != 1)
		{
			count++;
		}
	}

	//약수가 여러개
	sum = 1;
	if (count > 1)
	{

		while (sum < max)
		{
			for (int i = 2; i <= num; i++)
			{
				if (num % i == 0)
				{
					num /= i;
					vArr.push_back(i);
					sum *= i;
					break;
				}
			}
		}
	}


	if (count == 1)
	{
		cout << max << endl;
	}
	else
	{
		for (int x : vArr)
		{
			cout << x << endl;
		}
	}

	return 0;
}
```
