
# 꼬마 정민

링크 : https://www.acmicpc.net/problem/11382




## 문제

꼬마 정민이는 이제 A + B 정도는 쉽게 계산할 수 있다. 이제 A + B + C를 계산할 차례이다!

## 입력

첫 번째 줄에 A, B, C (1 ≤ A, B, C ≤ 1012)이 공백을 사이에 두고 주어진다.

## 출력

A+B+C의 값을 출력한다.

## 예제 입력 1

77 77 7777

## 예제 출력 1

7931

---
**실행 1(성공)**

```c++
#include <iostream>

using namespace std;

int main()
{	
	long long A, B, C;

	cin >> A >> B >> C;
	
	cout << A + B + C << endl;

	return 0;
}

```
