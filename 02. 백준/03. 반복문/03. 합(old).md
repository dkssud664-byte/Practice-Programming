
# 합

링크 : https://www.acmicpc.net/problem/8393




## 문제

n이 주어졌을 때, 1부터 n까지 합을 구하는 프로그램을 작성하시오.

## 입력

첫째 줄에 n (1 ≤ n ≤ 10,000)이 주어진다.

## 출력

1부터 n까지 합을 출력한다.

## 예제 입력 1

3

## 예제 출력 1

6


---
**실행 1(성공)**

```c++
#include <iostream>

using namespace std;

int main()
{
	int n;
	int sum = 0;

	cin >> n;
	for (int i = 1; i <= n; i++)
	{
		sum += i;
	}		
	cout << sum << endl;
	
	return 0;
}
```
