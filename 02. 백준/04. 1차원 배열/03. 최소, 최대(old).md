
# 최소, 최대

링크 : https://www.acmicpc.net/problem/10818





## 문제

N개의 정수가 주어진다. 이때, 최솟값과 최댓값을 구하는 프로그램을 작성하시오.

## 입력

첫째 줄에 정수의 개수 N (1 ≤ N ≤ 1,000,000)이 주어진다. 둘째 줄에는 N개의 정수를 공백으로 구분해서 주어진다. 모든 정수는 -1,000,000보다 크거나 같고, 1,000,000보다 작거나 같은 정수이다.

## 출력

첫째 줄에 주어진 정수 N개의 최솟값과 최댓값을 공백으로 구분해 출력한다.

## 예제 입력 1

5
20 10 35 30 7

## 예제 출력 1

7 35

---
**실행 1(성공)**

```c++
#include <iostream>

using namespace std;

int main()
{
	int n, a, b;
	cin >> n ;

	int* arr = new int[n]();

	for (int i = 0; i < n; i++)
	{
		cin >> arr[i];		
	}
	a = arr[0];
	b = arr[0];
	for (int i = 0; i < n; i++)
	{
		if (a > arr[i])
		{
			a = arr[i];
		}
		else if(b < arr[i])
		{
			b = arr[i];
		}
	}
	cout << a << " " << b << endl;

	
	delete[] arr;
		
	return 0;
}
```
